# Legal AI Document Intake & Classification

**Status:** In development

## Project Overview

This portfolio project explores how structured document classification, data annotation, and quality assurance can support legal operations workflows.

## Objectives

- Classify fictional legal documents according to defined annotation rules.
- Extract relevant document metadata.
- Identify ambiguous documents requiring human review.
- Develop a reproducible quality assurance process.
- Eventually analyze operational performance using SQL.

## Initial Document Types

- Non-Disclosure Agreements (NDAs)
- Employment Agreements
- Court Documents
- Unknown / Needs Review

## Methodology

The project begins with manually annotated synthetic documents and documented classification guidelines. Later phases will introduce automated classification and compare its output against reviewed reference labels.

## Data Privacy

All initial documents are fictional. No confidential client or employer data is used.
